Owner decision 2026-11-20: pre-algebra is the next content area after fractions.
It's what Integrated Math 1 leans on most, and it builds on what's already built
(whole numbers, integers, fractions), so the diagnostic can follow a gap all the
way down.

## Skills (draft graph: `curriculum/graph/alg.json`)

| Skill | Parts (diagnostic subskills) | Rests on |
|---|---|---|
| Order of operations | no parentheses (2 + 3 × 4); parentheses; with integers (−2 + 3 × (−4)) | whole/integer operations |
| Exponents | evaluate (2⁴, 5²); negative bases ((−3)² vs −3²); in order of operations (2 + 3²) | multiplication facts, integer multiplying |
| One-step equations | x + 5 = 12; 3x = 21; x/4 = 6; with negatives and fractions (x − 3 = −8, ⅔x = 10) | integer add/subtract, integer multiply/divide, fraction multiply/divide |
| Two-step equations | 3x + 5 = 20; x/2 − 4 = 3; with negatives | one-step equations, order of operations |
| Distributive property | 3(x + 4) → 3x + 12; −2(x − 5) → −2x + 10 | integer multiplying |
| Combining like terms | 3x + 5x; 4x + 3 − x + 7 | integer add/subtract |

Later (not in this plan): equations with variables on both sides, equations
that need distributing first, inequalities, evaluating expressions with variables.

## Build order

1. **Order of operations and exponents.** Answers are numbers, so the keypad,
   grading and diagnostic work as they are. Exponents need the problem display
   to show a raised number (small change).
2. **One- and two-step equations.** Students answer "x = ?" with a number (whole,
   negative or fraction), so again no new input method. The worked solutions
   show "do the same to both sides".
3. **Distributive property and combining like terms.** These answers are
   expressions (3x + 12), so this step needs the new input piece: an "x" key on
   the keypad and an answer checker that accepts any equivalent way of writing it
   (12 + 3x, 3x+12) but asks for simplest form. Planned early, built last.

Each skill gets what the fractions skills have: generators with levels, the
common mistakes as wrong-answer patterns (e.g. adding before multiplying,
−3² = 9, 3(x + 4) = 3x + 4, 3x + 5 = 8x), worked solutions, a lesson, a paper
test with checked keys, and diagnostic tests with pretend students.
