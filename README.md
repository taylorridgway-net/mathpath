# MathPath

Free, open-source gap-recovery math platform for high school students. **Early prototype, not ready for students.**

- Vision and requirements: [docs/BRIEF.md](docs/BRIEF.md)
- Current plan and decisions: [docs/PLAN.md](docs/PLAN.md) and [CLAUDE.md](CLAUDE.md)
- Draft list of every skill, for review: [docs/SKILL-LIST.md](docs/SKILL-LIST.md)
- The skill graph itself: [curriculum/graph/](curriculum/graph/)

## Running the tests

Needs Node.js 20 or newer. Nothing to install.

```bash
npm test
```
